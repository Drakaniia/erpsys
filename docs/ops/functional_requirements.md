# ERPSYS Functional Requirements

| User Type          | Component                | Functional Requirement                | Description                                                                                                                        |
| ------------------ | ------------------------ | ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| STUDENT            | Authentication           | Student Registration                  | STUDENT should be able to register a student account using a student number and personal email address.                            |
| STUDENT            | Authentication           | Student Login                         | STUDENT should be able to sign in using email and password or Google OAuth.                                                        |
| STUDENT            | Step Progression         | View Enrollment Progress              | STUDENT should be able to view their enrollment step progress and current statuses for the active academic year.                   |
| STUDENT            | Step Progression         | Apply for Assessment                  | STUDENT should be able to apply for the assessment step to initiate the verification process.                                      |
| STUDENT            | Evidence Management      | Upload Enrollment Evidence            | STUDENT should be able to upload evidence files such as screenshots and scans for enrollment steps.                                |
| STUDENT            | Evidence Management      | Submit and Delete Evidence            | STUDENT should be able to submit evidence for officer review and delete previously uploaded files.                                 |
| STUDENT            | Enrollment Queue         | Join Enrollment Queue                 | STUDENT should be able to join the enrollment queue for a department with an open adviser.                                         |
| STUDENT            | Enrollment Queue         | View and Leave Queue                  | STUDENT should be able to view their queue position and leave the queue before being served.                                       |
| STUDENT            | Notifications            | View Notifications                    | STUDENT should be able to view notifications for step verification updates and queue status changes.                               |
| STUDENT            | Notifications            | Mark Notifications as Read            | STUDENT should be able to mark all unread notifications as read.                                                                   |
| SBO_OFFICER        | Authentication           | SBO Officer Login                     | SBO_OFFICER should be able to sign in using email and password or Google OAuth.                                                    |
| SBO_OFFICER        | Authentication           | SBO Officer Logout                    | SBO_OFFICER should be able to sign out from the system.                                                                            |
| SBO_OFFICER        | Submission Review        | Filter Student Submissions            | SBO_OFFICER should be able to list student submissions filtered by step, status, and date range.                                   |
| SBO_OFFICER        | Submission Review        | View Submission Details               | SBO_OFFICER should be able to view detailed submission information including student data, evidence, and verification history.     |
| SBO_OFFICER        | Verification Actions     | Verify Submission with Digital Stamp  | SBO_OFFICER should be able to verify a student's step submission with a digital stamp.                                             |
| SBO_OFFICER        | Verification Actions     | Return or Revoke Verification         | SBO_OFFICER should be able to return a submission with feedback chips and notes or revoke a verified stamp.                        |
| SBO_OFFICER        | Social Media Management  | Add and Edit Social Media Links       | SBO_OFFICER should be able to add and edit social media links for students to follow.                                              |
| SBO_OFFICER        | Social Media Management  | Reorder and Delete Social Media Links | SBO_OFFICER should be able to reorder and delete social media links.                                                               |
| SBO_OFFICER        | Profiling Form           | View Profiling Form URL               | SBO_OFFICER should be able to view the current profiling form URL for the active academic year.                                    |
| SBO_OFFICER        | Profiling Form           | Manage Profiling Form URL             | SBO_OFFICER should be able to set or update the profiling form URL.                                                                |
| SBO_OFFICER        | Verification Stamp       | View Verification Stamp               | SBO_OFFICER should be able to view their current verification stamp name, graphic, and signature.                                  |
| SBO_OFFICER        | Verification Stamp       | Update Verification Stamp             | SBO_OFFICER should be able to update their stamp name and upload stamp graphic and signature images.                               |
| SBO_OFFICER        | Mugshot Review           | Review Student Mugshot                | SBO_OFFICER should be able to review and verify student mugshot photos.                                                            |
| SBO_OFFICER        | Consent Review           | Review Student Consent                | SBO_OFFICER should be able to review and verify student consent form scans.                                                        |
| SBO_OFFICER        | Reports                  | Generate Officer Reports              | SBO_OFFICER should be able to generate PDF reports for their assigned verification steps.                                          |
| ENROLLMENT_OFFICER | Authentication           | Enrollment Adviser Login              | ENROLLMENT_ADVISER should be able to sign in using email and password or Google OAuth.                                             |
| ENROLLMENT_OFFICER | Authentication           | Enrollment Adviser Logout             | ENROLLMENT_ADVISER should be able to sign out, automatically closing any open department availability.                             |
| ENROLLMENT_OFFICER | Availability Management  | Manage Department Availability        | ENROLLMENT_ADVISER should be able to toggle their department availability open or closed to accept students.                       |
| ENROLLMENT_OFFICER | Availability Management  | Maintain Adviser Availability         | ENROLLMENT_ADVISER should be able to send a heartbeat to keep their availability alive and prevent auto-close.                     |
| ENROLLMENT_OFFICER | Queue Monitoring         | Monitor Department Queues             | ENROLLMENT_ADVISER should be able to view their mapped department queues with waiting counts and serving status.                   |
| ENROLLMENT_OFFICER | Queue Monitoring         | View Enrolled Students                | ENROLLMENT_ADVISER should be able to view a list of enrolled students by department.                                               |
| ENROLLMENT_OFFICER | Queue Actions            | Serve Next Student                    | ENROLLMENT_ADVISER should be able to begin serving the next student in the FIFO queue.                                             |
| ENROLLMENT_OFFICER | Queue Actions            | End or Requeue Student                | ENROLLMENT_ADVISER should be able to end serving a student or move the first student to the end of the queue.                      |
| ENROLLMENT_OFFICER | Enrollment Processing    | Complete Student Enrollment           | ENROLLMENT_ADVISER should be able to complete a student's enrollment after all prerequisite steps are verified.                    |
| ENROLLMENT_OFFICER | Enrollment Processing    | Revert Completed Enrollment           | ENROLLMENT_ADVISER should be able to revert a single or multiple completed enrollments back to the waiting queue.                  |
| ENROLLMENT_OFFICER | Department Management    | Manage Department Details             | ENROLLMENT_ADVISER should be able to create and update department details.                                                         |
| ENROLLMENT_OFFICER | Department Management    | Assign Adviser to Department          | ENROLLMENT_ADVISER should be able to assign themselves to a department or delete an empty department.                              |
| ENROLLMENT_OFFICER | Students Tab             | View Student Roster                   | ENROLLMENT_ADVISER should be able to view a roster of students across their assigned departments.                                  |
| ENROLLMENT_OFFICER | Reports                  | Generate Instructor Reports           | ENROLLMENT_ADVISER should be able to generate PDF reports for their departments.                                                   |
| ADMIN              | Authentication           | Admin Login                           | ADMIN should be able to sign in using email and password or Google OAuth.                                                          |
| ADMIN              | Authentication           | Admin Logout                          | ADMIN should be able to sign out from the system.                                                                                  |
| ADMIN              | Dashboard Overview       | View Dashboard Statistics             | ADMIN should be able to view system statistics including user role counts, step verification totals, and department queue tallies. |
| ADMIN              | Dashboard Overview       | View Administrative Audit Log         | ADMIN should be able to view recent administrative activity in the audit log.                                                      |
| ADMIN              | User Management          | Manage and Search Users               | ADMIN should be able to list and search users with filters for role, organization status, and sort order.                          |
| ADMIN              | User Management          | Change User Roles                     | ADMIN should be able to change individual user roles between student and SBO officer or bulk change roles for multiple users.      |
| ADMIN              | Password Management      | Search Student Users                  | ADMIN should be able to search for student users by name, email, or student number.                                                |
| ADMIN              | Password Management      | Reset Student Password                | ADMIN should be able to reset a student's password by generating a new one.                                                        |
| ADMIN              | Department Management    | Manage Department Names and Codes     | ADMIN should be able to create and update department names and codes.                                                              |
| ADMIN              | Department Management    | Activate or Deactivate Departments    | ADMIN should be able to activate or deactivate departments.                                                                        |
| ADMIN              | Academic Year Management | Manage Academic Years                 | ADMIN should be able to create, edit, and delete academic years.                                                                   |
| ADMIN              | Academic Year Management | Activate Academic Year                | ADMIN should be able to activate an academic year and preview its impact before activation.                                        |
| ADMIN              | Adviser Mapping          | View Adviser Department Assignments   | ADMIN should be able to list all advisers with their current department assignments.                                               |
| ADMIN              | Adviser Mapping          | Assign Advisers to Departments        | ADMIN should be able to assign advisers to departments.                                                                            |
| ADMIN              | Requirement Management   | Manage Assessment Requirements        | ADMIN should be able to create, edit, and delete requirement items for the assessment step.                                        |
| ADMIN              | Requirement Management   | Reorder Assessment Requirements       | ADMIN should be able to reorder requirement items by moving them up or down.                                                       |
| ADMIN              | Chatbot Knowledge        | View Chatbot Knowledge                | ADMIN should be able to view the current chatbot knowledge document and its version.                                               |
| ADMIN              | Chatbot Knowledge        | Update Chatbot Knowledge              | ADMIN should be able to update the chatbot knowledge document used by the enrollment assistant.                                    |
| ADMIN              | Reports                  | Generate Admin Reports                | ADMIN should be able to generate PDF reports for administrative purposes.                                                          |
